Trung Tâm Trợ Giúp & Bản Quyền

Hướng dẫn sử dụng, xử lý sự cố thường gặp và chính sách thiết bị

⚡
Yêu cầu quyền Administrator: Luôn click chuột phải vào file ứng dụng và chọn "Run as Administrator" để cấp quyền bind cổng mạng và cấu hình socket mượt mà trên Windows.
01. Quản Lý & Thêm Tài Khoản VPN (Tab Cài Đặt)
▼

💡 Lưu ý quan trọng: Ngoại trừ PIA, hầu hết các hãng VPN đều sử dụng Thông tin kết nối riêng biệt (Credentials / Private Key) được cấp trong trang quản lý tài khoản web, không dùng mật khẩu đăng nhập email thông thường.

• Private Internet Access (PIA): Nhập Username + Password. Hệ thống tự động xác thực token API để chạy đồng thời cả WireGuard lẫn OpenVPN.

• WireGuard (Surfshark, ProtonVPN, NordVPN, Mullvad...): Đăng nhập trang quản lý tài khoản trên website → vào mục Manual setup / WireGuard để lấy Private Key (chuỗi khóa bí mật 44 ký tự) hoặc dán toàn bộ nội dung file cấu hình .conf.

• OpenVPN (ExpressVPN, CyberGhost, IPVanish, HMA, VyprVPN...): Đăng nhập trang cá nhân trên web → vào mục Manual Setup / OpenVPN:
1. Lấy VPN Username & VPN Password chuyên dụng (chuỗi ký tự ngẫu nhiên do hãng cấp riêng cho OpenVPN).
2. Tải 1 file cấu hình mẫu .ovpn bất kỳ của hãng và dán nội dung vào ô tương ứng.

📌 Khi bấm nút [+ Thêm tài khoản] và chọn loại Provider trong Tab Cài Đặt, hệ thống luôn có sẵn gợi ý và form mẫu điền sẵn để bạn thao tác 1-Click cực nhanh.
02. Tạo Nhóm Proxy IPv4 qua VPN (Tab Proxy via VPN)
▼

• Dải cổng mặc định: 10000 – 19999. Hệ thống tự động nhảy cổng trống tiếp theo (10010, 10020...).

• Tùy chọn: Chọn Nhà cung cấp → Quốc gia (hoặc Random Toàn Cầu) → Loại proxy (HTTP / SOCKS5) → Số lượng cổng → Bật Xác thực User/Pass nếu cần.

💡 Mẹo nhân đôi Proxy (x2 IPs): Cùng 1 tài khoản VPN, bạn có thể tạo 1 nhóm WireGuard + 1 nhóm OpenVPN để khai thác tối đa 100% số lượng IP độc lập!
03. Tạo Nhóm Proxy IPv6 (Tab Proxy IPv6)
▼

• Dải cổng mặc định: 20000 – 29999.

• Cách dùng: Chọn Card mạng (Ethernet/Wi-Fi) đã được nhà mạng cấp IPv6 → Nhập số lượng cổng → Hệ thống tự động gán hàng trăm IP ngẫu nhiên vào Card mạng và hỗ trợ tự động xoay dải IPv6 ngầm định kỳ.

04. Tạo Proxy DCOM 4G/5G (Tab DCOM 4G/5G)
▼

• Dải cổng mặc định: 40000 – 49999.

• Dcom HiLink (Web API): Điền IP Gateway của Dcom (vd: 192.168.8.1).

• Dcom Modem COM (Rasdial): Chọn đúng cổng COM và tên Dial-up kết nối mạng di động.

05. Chuyển SOCKS sang HTTP (Tab SOCKS to HTTP)
▼

• Dải cổng mặc định: 30000 – 39999.

• Chức năng: Chuyển tiếp bất kỳ Proxy SOCKS5 nguồn nào thành HTTP Proxy nội bộ cực nhanh để cấp cho các phần mềm MMO/Bot không hỗ trợ giao thức SOCKS5.

06. Kiểm Tra Proxy (Tab Check Live)
▼

• Kiểm tra Live: Dán danh sách proxy → Chọn số luồng → Bấm [▶️ Bắt đầu kiểm tra] để xác thực Real WAN IP và cờ quốc gia.

• Bấm [🔄 Xoay ngay] hoặc [Xoay Proxy Die]. Hệ thống tích hợp cơ chế Auto-Fallback tự động thử nghiệm qua nhiều server thay thế nếu gặp server nghẽn.

• Tích hợp Webhook cho Bot MMO: Gửi request HTTP GET/POST tới:
http://localhost:8000/api/rotate?port=10000 để xoay IP 1-Click từ bất kỳ Tool tự động hóa nào!

01. Proxy Báo "Die" Hoặc Không Kiểm Tra Được Real WAN IP
▼

• Nguyên nhân: Máy chủ VPN bên ngoài tạm thời quá tải hoặc tài khoản VPN bị hết hạn / đổi mật khẩu.

• Cách xử lý:

1. Bấm nút [🔄 Xoay ngay] trên Card proxy hoặc nút [Xoay Proxy Die] trong tab Check Live. Hệ thống sẽ kích hoạt cơ chế Auto-Fallback tự động bốc và đổi sang Server VPN khỏe khác trong 1-2 giây.

2. Kiểm tra lại hạn sử dụng tài khoản VPN trong Tab Cài đặt & Tài khoản.

02. Lỗi Không Nhận Card Mạng Hoặc Báo "Access Denied" (IPv6)
▼

• Nguyên nhân: Ứng dụng chưa được cấp quyền quản trị cao nhất trên Windows để gán dải IPv6.

• Cách xử lý: Tắt hẳn phần mềm, click chuột phải vào file ứng dụng → chọn "Run as Administrator". Đảm bảo router nhà mạng (Viettel/VNPT/FPT) đã kích hoạt IPv6.

03. Dcom 4G/5G Không Tự Động Xoay Được IP Mới
▼

• Dcom HiLink (Web API): Kiểm tra Gateway IP trên thanh trình duyệt (mặc định là 192.168.8.1). Đảm bảo không bị phần mềm khác khóa Web UI của Dcom.

• Dcom Modem COM: Mở Device Manager trên Windows → kiểm tra đúng số cổng COM của Dcom và kiểm tra SIM 4G còn dung lượng data.

04. Mạng Chậm Hoặc Ping Cao Khi Dùng Proxy
▼

• Cách tối ưu: Khi tạo nhóm, nên ưu tiên chọn các quốc gia gần Việt Nam như Singapore (SG), Hong Kong (HK), Japan (JP) để có ping cực thấp (30-60ms) và băng thông tối đa.

• Ưu tiên dùng giao thức WireGuard để có tốc độ truyền tải nhanh gấp 2-3 lần OpenVPN truyền thống.

05. Xung Đột Cổng (Port In Use) Hoặc Cổng Bị Treo Ngầm
▼

• Cách xử lý: Vào Tab Cài Đặt & Tài Khoản → Bấm nút [🧹 Tiến hành dọn dẹp (Clean System)]. Hệ thống sẽ tự động quét và ngắt toàn bộ tiến trình rác mồ côi, giải phóng 100% cổng mạng ngay lập tức.
